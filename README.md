# Peter & Sam — Animated Wedding Invitation

A cinematic, interactive wedding-card invitation.

## Files

- `index.html` — main page / entry point
- `style.css` — design and animations
- `script.js` — interactions and effects
- `assets/` — assets folder for future images or media

## Run

Open `index.html` in Chrome or Edge.

## Deploy

This is a static HTML/CSS/JavaScript project. Upload the complete folder to Vercel (or another static host). No build command or framework is required.

## Main interaction

Click the bride/screen to trigger the bouquet animation, followed by bokeh/petals and the envelope opening sequence.
